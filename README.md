# College Event Management System

A professional College Event Management Portal built using HTML, CSS, and JavaScript.

## Features

- Admin Login
- Event Creation
- Event Registration
- Event Search
- Registration Progress Tracking
- Responsive Design
- Glassmorphism UI
- Dark Mode Support

## Project Structure

project/
│
├── admin-login.html
├── admin.html
├── user.html
├── style.css
├── admin.js
├── user.js
└── college.jpg

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage

## How to Run

1. Download the project.
2. Place all files in one folder.
3. Open `admin-login.html`.
4. Login using:
   - Password: admin123
5. Create events from the Admin Dashboard.
6. Open `user.html` to view and register for events.
